# OCR | استخراج متن

ابزار مستقل استخراج متن چاپی فارسی و انگلیسی از تصویر؛ دیگر زیرمجموعهٔ MathMate نیست.

## ساختار پوشه‌ها

```text
OCR/
├── index.html
├── style.css
├── app.js
├── manifest.webmanifest
├── capacitor.config.json
├── package.json
├── assets/
│   ├── font/AradVF.ttf          ← فایل فونت را اینجا قرار بده
│   ├── favicon/OCR.png          ← آیکون را اینجا قرار بده
│   └── ocr-runtime/             ← منابع موتور برای APK (توسط GitHub Actions ساخته می‌شود)
├── scripts/build-web.mjs
├── scripts/prepare-android-assets.mjs
└── .github/workflows/android-apk.yml
```

## افزودن فونت و آیکون

- فونت: `AradVF.ttf` را داخل `assets/font/` قرار بده.
- آیکون: تصویر مربعی `OCR.png` را داخل `assets/favicon/` قرار بده. همین تصویر در تب مرورگر، سربرگ و manifest معرفی شده و در ساخت APK نیز به‌عنوان منبع آیکون برنامه استفاده می‌شود؛ برای آیکون لانچر اندروید بهتر است PNG مربعی 1024×1024 باشد؛ گردش‌کار آن را برای آیکون‌های اندروید هم به کار می‌برد.
- پایین صفحه عبارت «توسط حسین ثقفی» درج شده است.

## اجرای وب و آماده‌سازی آفلاین

1. روی HTTPS یا localhost اجرا کن.
2. در اولین اجرا اینترنت روشن باشد.
3. زبان را انتخاب و «آماده‌سازی برای استفاده آفلاین» را بزن.
4. نسخهٔ وب، فایل‌های موتور، هستهٔ WASM و مدل زبان انتخابی را از مسیر Service Worker دریافت و در Cache Storage بررسی می‌کند.
5. همان آدرس را در همان مرورگر باز کن.

## ساخت APK با GitHub Actions

1. فایل فونت و آیکون را در مسیرهای بالا اضافه کن.
2. کل محتویات پروژه را در یک مخزن GitHub جدید آپلود کن.
3. از زبانهٔ **Actions**، گردش‌کار **Build Android APK** را انتخاب کن.
4. روی **Run workflow** بزن (یا به شاخهٔ main/master پوش کن).
5. گردش‌کار ابتدا فایل‌های مدل `fas` و `eng` را دریافت و در سه مرحله بررسی می‌کند: پوشهٔ منبع، پوشهٔ `www` و منابع Android.
6. پس از موفقیت، وارد اجرای workflow شو و از بخش **Artifacts** فایل `OCR-Text-Android-APK` را دانلود کن. فقط APK همین اجرای موفق را نصب کن.

این گردش‌کار پروژهٔ Android را با Capacitor تولید می‌کند، موتور Tesseract و مدل‌های fas/eng را داخل APK قرار می‌دهد، سپس وجود واقعی هر دو فایل مدل را داخل خود APK بررسی می‌کند و در پایان APK آزمایشی (debug) می‌سازد. برای انتشار عمومی در فروشگاه، باید APK/AAB امضاشدهٔ release و کلید امضای خصوصی جداگانه تنظیم شود.

## محدودهٔ OCR

برای متن چاپی فارسی و انگلیسی است؛ ابزار تخصصی تشخیص دست‌خط، شماره‌ها یا فرمول‌های ریاضی نیست. خروجی را بازبینی کن.

## اجرای محلی

نسخهٔ وب را با یک وب‌سرور محلی یا HTTPS باز کن؛ بازکردن مستقیم `index.html` برای Service Worker کافی نیست. برای ساخت APK، GitHub Actions وابستگی‌های Node/Android را روی Runner نصب می‌کند و کاربر نهایی نیازی به نصب آن‌ها ندارد.

## رفع خطای «فایل همراه برنامه پیدا نشد: lang/fas.traineddata.gz»

این خطا یعنی فایل مدل فارسی در APK نصب‌شده وجود ندارد. نسخهٔ اصلاح‌شدهٔ گردش‌کار، فایل‌های مدل را بعد از `cap sync` به‌صورت صریح در `android/app/src/main/assets/public/assets/ocr-runtime/` کپی می‌کند و قبل از انتشار Artifact، حضور آن‌ها را داخل APK بررسی می‌کند. اگر هر مرحله‌ای شکست بخورد، ساخت متوقف می‌شود و APK ناقص تحویل نمی‌دهد. بعد از دریافت Artifact جدید، APK قبلی را حذف و APK جدید را نصب کن.

**توجه:** `assets/favicon/OCR.png` و `assets/font/AradVF.ttf` باید فایل‌های اصلی پروژه باشند؛ آن‌ها را از نسخهٔ کامل خودت حفظ کن و با فایل نمونه یا خالی جایگزین نکن.
